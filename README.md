# MiniLM
- The model used is `MiniLM-L6-v2`, which generates text embeddings with a dimension of 384.
- The maximum sequence length supported is 256 tokens.
- The model is based on a Transformer architecture and incorporates Pooling and Normalize modules.

This setup ensures that users can easily understand and test the MiniLM embedding model functionality within the project.

## Installation
Python dependencies in this project are handled by uv,
check the documentation here: https://docs.astral.sh/uv/ .

### Local installation on Linux

```sh
chmod +x setup.sh
./setup.sh
```

## Usage

### Embedding Text

The `/embed` endpoint allows you to generate embeddings for a given text using the MiniLM model. The endpoint requires a query parameter `text` which is the text for which you want to generate the embedding.

#### Example Usage

You can test the `/embed` endpoint using the `curl` command:

```sh
curl -X GET "http://127.0.0.1:8000/embed?text=Hello%20World"
```

#### Response

The endpoint will return a JSON response containing the following information:

- `tokens`: The tokens generated by the tokenizer.
- `token_ids`: The IDs of the tokens.
- `attention_mask`: The attention mask for the tokens.
- `token_type_ids`: The token type IDs.
- `embedding`: The generated embedding.

Example response:

```json
{
  "tokens": ["Hello", "World"],
  "token_ids": [101, 2057, 2026, 102],
  "attention_mask": [1, 1, 1, 1],
  "token_type_ids": [0, 0, 0, 0],
  "embedding": [[...]]  # Embedding vector of length 384
}
```
